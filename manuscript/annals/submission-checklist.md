# Submission checklist — Annals of the New York Academy of Sciences

Guideline snapshot checked 2026-10-19: Original Articles are 2,500–7,000 words excluding abstract, online Methods, references, and figure legends; abstract ≤200 words; 4–8 figures and/or tables; ≤175 references. Confirm the current online instructions immediately before submission.

## Package drafted

- [x] Original Article manuscript with title, abstract, keywords, Introduction, Methods, Results, Discussion, Conclusion, declarations placeholders, references, and legends.
- [x] Five selected main figures with vector and raster output (Figure 1: `figures/build_reference_style_figure.py`; Figures 2–5: `figures/build_figures.py`; see `figures/README.md`).
- [x] Supplementary Information with data coverage, counts, quantification settings, module checks, and limitations.
- [x] Cover letter draft scoped to the evidence.
- [x] Data availability statement naming repository and public accessions.

## Author verification still required

- [ ] Final author list/order, affiliations, corresponding author, postal address, ORCIDs.
- [ ] CRediT contributions, funding, acknowledgments, competing-interest statement, ethics statement if requested.
- [ ] Confirm each author reviewed and approved the complete manuscript, figures, and declarations.
- [ ] Replace repository branch URL with immutable commit and preferably a permanent Zenodo/archive DOI; confirm license terms for software and redistributed data.
- [ ] Confirm journal accepts the article type and confirm the scope framing with the editor if needed.
- [ ] Export figures at journal-compliant resolution/formats and upload each figure separately; upload editable tables and Supplementary Information as separate files.
- [ ] Recheck word count, abstract, figure/table count, references, citations, and current journal submission portal requirements.
- [ ] Have domain authors review all scientific claims, taxon/resource descriptions, and bibliography against source records.

No submission should be made until author-controlled declarations and final scientific review are complete.
