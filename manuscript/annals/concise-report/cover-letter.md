Dear Editor,

Please consider our Concise Report, “PhytoScope for portable local queries of plant genome data.” The report examines a general research-infrastructure problem: how researchers studying underrepresented plants can query public genome annotations, sequences, and expression files through one reusable local framework.

The same application code was evaluated across seven plant species. Independent checks recovered 4,641,758 recognized structural tuples, verified selected sequence products at 15 coding loci, and reconciled all 34,914 output gene identifiers from a public ricebean expression calculation to a fixed RefSeq release. One main figure connects the workflow, a real locus example, and these complementary validation results. Detailed inputs, procedures, and task-specific checks accompany the report as Supporting Information.

The contribution is a technically evaluated query framework whose portability can be assessed from source-derived outputs. The public expression case retains the distinction between IC426787 reads and the VRB3 reference cultivar. Its result concerns data import and identifier reconciliation. This focus should be useful to readers interested in plant genomics, reusable research software, and access to dispersed public data.
