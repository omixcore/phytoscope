# Figure 1 legend

## English

**Figure 1. PhytoScope connects public plant data to a shared local query framework with independent validation.** **(a)** Compatible annotations, matching genome sequences, and expression matrices with sample labels are supplied by users. Plant symbols denote crop, medicinal, and ornamental use cases and are schematic. **(b)** The same import and query code links sequence identifiers, coordinates, loci, transcripts, and recognized feature relationships. A schematic hierarchy illustrates the data model; it is not a species-specific chromosome inventory or a literal application screenshot. Project inputs, selected locus state, and results can be saved and reopened. **(c)** Source-derived rice-bean examples illustrate output content. The minus-strand locus LOC124833352 on NC_142174.1 spans positions 16,647–23,821; XM_088100767.1 has three exons, a 2,060-nt transcript, a 1,983-nt GFF3 CDS including the terminal stop codon, and a 660-aa protein. Terminal UTR intervals are inferred because this source annotation lacks explicit UTR rows. The separate expression example shows individual TPM values for LOC148191553 (0.391983, 26.876721, and 9.115288); R1–R3 correspond to SRR16122599, SRR16122608, and SRR16122607. No group mean, inferential statistic, or differential-expression result is shown. **(d)** Independent source-to-model comparisons across eight inventories in four reference plant systems recover 4,641,758 recognized structural tuples with zero missing or extra tuples; bars share a linear scale, so small excerpt counts are nearly invisible. Sequence checks cover five coding loci per additional plant (15 loci and 25 coding transcripts in total); span, spliced RNA, and CDS are checked with strand-aware sequence hashes. All 34,914 rice-bean expression gene IDs match the pinned RefSeq annotation. Reads from IC426787 were quantified against the VRB3 reference, supporting import and identifier compatibility rather than genotype-matched expression biology. These task-specific denominators do not represent a pooled accuracy estimate or universal compatibility claim.

## 中文

**图1 PhytoScope 将公开植物数据连接到统一的本地查询框架，并通过独立证据核验输出。** **（a）** 用户提供兼容的注释、匹配的基因组序列，以及带样本标签的表达矩阵；植物图标仅示意作物、药用植物和观赏植物等使用场景。**（b）** 相同的导入与查询代码连接序列标识符、坐标、基因、转录本和支持的结构特征关系。层级图是数据模型示意，并非某物种的染色体清单或软件截图；输入、选定位点状态和结果可以保存及恢复。**（c）** 使用真实饭豆数据示例展示查询内容：负链基因 LOC124833352 位于 NC_142174.1 的 16,647–23,821 区间，转录本 XM_088100767.1 含三个外显子，转录本长度为2,060 nt，GFF3 CDS 为1,983 nt（包括终止密码子），蛋白质为660 aa。由于来源注释没有显式 UTR 特征，末端 UTR 标记为推断。另以 LOC148191553 展示三次生物学重复的真实 TPM 值；R1–R3 分别对应 SRR16122599、SRR16122608、SRR16122607，不展示组均值、显著性检验或差异表达结论。**（d）** 四个参考植物系统的八套来源清单累计核对4,641,758个支持的结构记录，无缺失或额外记录；条形使用相同线性比例，因此极小的节选数据条形几乎不可见。三个新增植物各选择五个编码基因位点，共15个位点、25个编码转录本，对基因组区间、剪接转录本及 CDS 进行考虑链方向的序列哈希核验。饭豆表达矩阵全部34,914个基因 ID 与固定版本的 RefSeq 注释匹配。原始材料 IC426787 与参考品种 VRB3 不同，因此只能支持导入和标识符兼容性，不能支持基因型匹配的表达生物学结论。不同验证项目的分母不能合并为统一准确率，也不能据此宣称普遍兼容。
