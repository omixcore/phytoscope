**Figure 1. PhytoScope links public plant data through a shared local query framework.** (a) User-supplied GFF3/GTF annotations, matching genome FASTA, and expression matrices with sample labels enter the workflow. (b) One import and query code path connects sequence identifiers, gene records, transcripts and recognized feature relationships across species. The model is schematic; inputs, locus state and results can be saved and reopened. (c) Source-derived rice-bean examples show minus-strand LOC124833352 on NC_142174.1, transcript XM_088100767.1, sequence lengths, and a separate expression example for LOC148191553. GFF3 CDS length includes the terminal stop codon; the protein length excludes it. Terminal UTRs are inferred because the annotation has no explicit UTR rows. R1–R3 show individual TPM values from IC426787 5-DPA biological replicates SRR16122599, SRR16122608 and SRR16122607, respectively; values are not group means. (d) The evaluation includes seven plant species. Eight source inventories yield 4,641,758 recognized structural tuples with zero missing or extra tuples. Sequence checks cover five selected coding loci per additional plant, totaling 15 loci and 25 coding transcripts. All 34,914 rice-bean expression gene IDs match the pinned annotation. IC426787 reads and the VRB3 reference represent different genotypes, limiting this expression check to import and identifier compatibility. Each denominator describes its own validation task.

**图1 PhytoScope 通过统一的本地查询框架连接公开植物数据。** （a）用户提供 GFF3/GTF 注释、匹配的基因组 FASTA，以及带样本标签的表达矩阵。（b）同一套导入和查询代码连接序列标识符、基因、转录本及支持的结构特征关系；数据模型为示意，输入、位点状态及结果可保存和恢复。（c）饭豆真实数据展示负链基因 LOC124833352、转录本 XM_088100767.1 的结构和序列长度，另以 LOC148191553 展示表达。GFF3 CDS 长度包括终止密码子，蛋白长度不包括终止符；来源注释缺少显式 UTR 特征，因此末端 UTR 标为推断。R1–R3 为 IC426787 在开花后5天的三个生物学重复，分别对应 SRR16122599、SRR16122608、SRR16122607，柱形为单个重复的 TPM，不是组均值。（d）评估覆盖七个植物物种，八套来源清单共核对4,641,758个支持的结构记录，无缺失和额外记录；三个新增植物各选择五个编码位点，共15个位点、25个编码转录本。饭豆表达矩阵全部34,914个基因 ID 与固定版本注释匹配。原始材料 IC426787 与参考品种 VRB3 不同，表达验证支持导入及标识符兼容性，各验证项目的分母分别解释。
