## 1. 目标与边界

- 目标：在固定任务集上收集**定性**可用性观察，供后续版本参考，并作为 future work 的显式记录。
- 边界：**不作定量性能/省时/发现率/易用性优劣结论**，不与 JBrowse2/IGV/TBtools 作「更快/更好」比较；
  与 `docs/fcs-tool-comparison-final.md` 的定性工具对照相互独立。
- 招募：≥ **3 名** 科研人员参与者（植物基因组/生物信息学相关背景，由作者 A6 招募）。

## 2. 固定五任务（与既有协议一致）

| # | 任务 | 固定输入 | 成功判据（仅记录，不评分） |
|---|---|---|---|
| T1 | 导入参考数据（GFF3 + FASTA + 可选表达矩阵），查看导入 health-check 报告 | 同一份冻结数据（如 `phytoscope-reference-data` 的 TAIR10/Araport11 或 `examples/arabidopsis-atlas/`） | 导入完成且报告可读；记录是否需外部帮助 |
| T2 | 按基因 ID 定位并查看基因结构（exon/CDS/UTR、链向） | 固定位点集，例如 `AT1G67090` / `AT5G38410` / `AT5G38430` | 能定位并读出结构；记录坐标/链向读取是否正确 |
| T3 | 挂载表达矩阵并查看样本分组 / measured-zero vs missing | 固定表达矩阵（如 `examples/arabidopsis-atlas/expression.tsv`） | 单位/样本顺序可读；记录零值与缺失是否被区分 |
| T4 | 生成多基因座比较图并导出 PNG/SVG/TSV | 固定 4 位点集 | 导出成功且文件可打开；记录单位/共享刻度观察 |
| T5 | 保存 `.phytoscope` 项目、关闭、重开并核对状态恢复 | T1–T4 的同一会话 | 重开后结构/表达/分析状态恢复；记录 checksum 提示是否清晰 |

## 3. 随机化与反平衡

- **工具顺序随机**：若同一参与者需在多个工具上执行相同任务，用拉丁方 / 随机排列平衡顺序，
  避免学习效应；记录每名参与者的实际顺序。
- **任务顺序固定**为 T1→T5；每任务计时可选（若计时须标 `current_measured` 并声明环境），
  **本批不预设任何时间数字**。
- 每名参与者独立会话，不共用缓存/项目文件。
